Installation

Install dependencies: sudo pacman -S qt6-base curl synctex djvulibre

Lektra is available in the Arch User Repository (AUR)

For the latest git version, run:

paru lektra-git # (or) yay -S lektra-git

Check out the releases page and download the latest DEB package for lektra.

Note

Tested successfully on Ubuntu 24.04

Check out the releases page and download the latest AppImage for lektra.

eselect repository enable gentoo-zh
emaint sync -r gentoo-zh
emerge lektra
NOTE

This package is maintained by douglarek, not by the upstream project. Please report Gentoo-specific issues to the gentoo-zh repository.

Install the dependencies for your distro

  1. qt6-base
  2. curl (OPTIONAL: if you want the LLM support (Work in Progress))
  3. synctex (OPTIONAL)
  4. djvulibre (OPTIONAL for djvu file support)
git clone https://github.com/dheerajshenoy/lektra.git
cd lektra
You'll have install.sh in the directory. Run --help to see the available options. 
./install.sh --help
Note about dependencies

The SyncTeX, DjVu and LLM features are OPTIONAL and can be disabled during installation to save space and reduce dependencies.
