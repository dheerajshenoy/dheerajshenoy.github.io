Commands
Commands (click to expand)

Commands are the core actions that Lektra can perform, such as copying text, navigating pages, or opening the command palette. Each command is associated with a unique identifier and can be triggered through various input methods.

Command palette - Ctrl + Shift + P (on a default configuration).

Example usage in config:

[keybindings]
selection_copy = "y,y"
scroll_down= "j"
