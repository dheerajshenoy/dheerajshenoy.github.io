Installation
Warning

lektra is still in alpha, crashes and bugs expected. Please submit issues here

Lektra is available in the Arch User Repository (AUR)

For the latest git version, run:

paru lektra-git # (or) yay -S lektra-git

Check out the releases page and download the latest DEB package for lektra.

Note

Tested successfully on Ubuntu 24.04

Check out the releases page and download the latest AppImage for lektra.

Install the dependencies for your distro

  1. qt6-base
  2. curl (OPTIONAL: if you want the LLM support (Work in Progress))
  3. synctex (OPTIONAL)
git clone https://github.com/dheerajshenoy/lektra.git
cd lektra
You'll have install.sh in the directory. Run --help to see the available options. 
./install.sh --help
