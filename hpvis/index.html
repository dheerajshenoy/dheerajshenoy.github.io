HpVis

A modern HEALPix viewer

HpVis is a viewer for HEALPix maps. The projection and the pixel lookup happen per pixel on the GPU, so a nside 2048 map still turns under your mouse.

Qt 6 · OpenGL · C++20
FITS · NPY · NPZ
AGPL-3.0

§1What it does

  • Fourteen projectionsMollweide to Gnomonic, from inside like the sky or outside like a globe, with sliders, poles and right-click recentering.
  • Three sky framesGalactic, Ecliptic and Equatorial, converted on the GPU from the map's own COORDSYS. Or a free trackball.
  • FITS, NPY and NPZRING and NESTED. The toolbar picks the HDU and column, or the array and row.
  • ColourFifteen colormaps and your own, linear, log and asinh scales, percentile range, colour bar.
  • MasksLoad several, toggle, invert, hide or dim the masked pixels.
  • Power spectraTT, TE, EE, BB, TB, EB, corrected for masks with MASTER, apodization, bandpowers and E/B purification.
  • Map expressionsAny expression of several maps. The result opens as a new tab and saves as FITS.
  • AnalysisStatistics, FITS headers, derivatives, E/B maps, unit conversion, random CMB realizations.
  • WorkspaceTabs, a file explorer dock, drag and drop, sessions that come back, and a shortcut for nearly every command.
  • ExportImages of the view, and plots as PNG, SVG or PDF in screen colours or black on white.

§3Libraries used

  • Qt 6 Interface, OpenGL rendering and plots
  • HEALPix C++ Pixelization and spherical harmonic transforms
  • libsharp Spherical harmonic transforms backend
  • NaMaster Mask-corrected power spectra (MASTER)
  • CLASS Theory spectra and CMB realizations
  • CFITSIO Reading and writing FITS files
  • libzip Reading NumPy .npz files
  • argparse Command-line arguments

§4Command line

# open a map
$ hpvis samples/wmap_W_iqu_nside32.fits
# pick a look
$ hpvis -p orthographic -m inferno -g map.fits
# render to a file, no window
$ hpvis --mask mask.fits --output out.png map.fits
# what's inside?
$ hpvis --info map.fits
$ hpvis --hdu 2 --column 3 maps.npz
--projection--colormap--cscale--orientation--view--graticule--mask--output--info--stats

Every option is described in the usage guide.

§5Dependencies and installation

Dependencies

HEALPix C++, libsharp, NaMaster and CLASS are built from the vendored sources, so you only install the rest from your distribution.

Dependency Needed for
C and C++20 compiler (GCC or Clang) everything
CMake 3.22+, make, pkg-config build system
Qt 6.8+ (Core, Gui, Widgets, OpenGLWidgets, Concurrent, Graphs, Svg) interface
OpenMP parallel code
CFITSIO reading and writing FITS files (system package)
libzip reading .npz files (system package)
autoconf, automake, libtool building the vendored HEALPix, libsharp and NaMaster
GSL, FFTW3 (with OpenMP), a CBLAS implementation NaMaster power spectra
git fetching the submodules
pandoc (optional) generating the man page

Install the packages

Arch Linux

sudo pacman -S base-devel cmake git pkgconf qt6-base qt6-graphs cfitsio libzip gsl fftw cblas-openblas autoconf automake libtool pandoc

Debian / Ubuntu

sudo apt install build-essential cmake git pkg-config qt6-base-dev qt6-graphs-dev libgl-dev libcfitsio-dev libzip-dev libgsl-dev libfftw3-dev libopenblas-dev autoconf automake libtool pandoc

Fedora

sudo dnf install gcc-c++ cmake git pkgconf-pkg-config qt6-qtbase-devel qt6-qtgraphs-devel cfitsio-devel libzip-devel gsl-devel fftw-devel openblas-devel autoconf automake libtool pandoc

Package names vary between distributions and releases. If one is not found, search for the library name.

Build

git clone --recurse-submodules https://github.com/dheerajshenoy/hpvis
cd hpvis
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/hpvis

The first build is slow because it compiles HEALPix and NaMaster. If you cloned without --recurse-submodules, run git submodule update --init --recursive. Pass -DWITH_NAMASTER=OFF to build without power spectrum support.

Install

sudo cmake --install build

# or without root
cmake -B build -S . -DCMAKE_INSTALL_PREFIX=$HOME/.local
cmake --build build -j && cmake --install build

This installs the hpvis binary, the bundled shared libraries in lib/hpvis/ and the man page. For a prefix in your home directory, make sure $HOME/.local/bin is in your PATH. More in the installation guide, including troubleshooting.
