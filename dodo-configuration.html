Configuration
dodo is configured through a single TOML file. No GUI wizards, no hidden state. Edit the file, restart dodo, and you’re done.
Introduction Example config LLM UI Window Layout Tabs Links Colors Rendering Behavior Keybindings Theming Notes

Introduction

By default, dodo looks for: ~/.config/dodo/config.toml

If the file doesn’t exist, dodo falls back to defaults.

The config is split into sections:

[llm]
[ui.*] // multiple ui sections like ui.scrollbars, ui.command_palette, etc.
[colors]
[rendering]
[behavior]
[keybindings]
Rule
Each section is independent. Remove what you don’t need.

Example config

This is a realistic minimal config that still keeps the “dodo feel”. 

# ~/.config/dodo/config.toml

[ui.layout]
mode = "top_to_bottom"
initial_fit = "width"

[ui.tabs]
visible = true
auto_hide = true

[ui.scrollbars]
search_hits = true

[behavior]
remember_last_visited = true
auto_reload = true
undo_limit = 25

[keybindings]
open_file = "o"
search = "/"
search_next = "n"
search_prev = "Shift+N"
command_palette = "Ctrl+Shift+P"
fullscreen = "F11"
Full reference
A complete config is included below in the per-section tables, matching the shipped defaults.

LLM (Optional)

Works only if dodo is compiled with LLM support. If not, these settings are ignored.

KeyTypeDescriptionDefault
providerstringLLM backend."ollama"
modelstringProvider model name."llama3.2:3b"
max_tokensintResponse length limit.512
 
[llm]
provider = "ollama"
model = "llama3.2:3b"
max_tokens = 512
Reality check
LLM is optional. dodo’s core workflow should not depend on it.

Links

KeyTypeDescriptionDefault
boundaryboolDraw link boundary boxes.false
detect_urlsboolDetect URL text and create links.true
url_regexstringRegex used for URL detection when detect_urls is enabled.(see below)
 
[ui.links]
boundary = false
detect_urls = true
url_regex = "(https?://|www\\.)[^\\s<>()\\\"']+"
Don’t make URL regex greedy
If you do, you will create garbage links everywhere.

Rendering

KeyTypeDescriptionDefault
dpifloatBase render DPI.72.0
dprfloat or mapDevice pixel ratio (global or per-output).(see example)
cache_pagesintHow many pages to keep in cache.4
antialiasing_bitsint4=good, 8=high.8
icc_color_profileboolEnable ICC color management.true
 
[rendering]
dpi = 72.0
dpr = { "eDP-1" = 1.25, "DP-5" = 1.0, "DP-7" = 1.0 }
cache_pages = 4
antialiasing_bits = 8
icc_color_profile = true
DPR
Use a map if you run mixed DPI monitors. Use a single float if you don’t care.

Theming

Kvantum is a powerful SVG-based theme engine for Qt. It supports dark themes, custom widgets, and integrates well with Qt6. It is available in the standard repository for your distribution. Once installed, select a theme in kvantummanager and set: 

export QT_STYLE_OVERRIDE=kvantum

Notes

Keep it in git
Your config matters. Treat it like code. Keep it versioned.
Restart needed
dodo reads config at startup. If you change config, restart.
