Getting started

Important
Most actions are meant to be done from the keyboard. If you’re trying to use dodo like a “normal” mouse-first reader, you’ll miss what makes it fast.

Open files

Use o to open a PDF. By default, dodo can open in a new window if you enable it in config. 

[behavior]
always_open_in_new_window = true

Modes

dodo has explicit interaction modes. No hidden state, no guessing.

ModeWhat it doesTypical binding
text_select_modeSelect and copy text.1
region_select_modeSelect a region (useful for screenshots/visual selection).2
annot_rect_modeCreate rectangle annotations.3
annot_select_modeSelect/edit existing annotations.4
text_highlight_modeHighlight text.5
annot_popup_modeCreate popup annotations.7
Config
You can choose the startup mode:
[behavior]
initial_mode = "text_select_mode"

Tabs

Tabs can be visible, auto-hidden, movable, and closable. You can also jump directly to tab 1–9. 

[ui.tabs]
visible = true
auto_hide = true
closable = true
movable = true
bar_position = "bottom"

Navigation

Scrolling (vim-style)

Default movement is vim-style: h j k l.

History jump

dodo tracks your jump history so you can go back and forward like a browser. Use Ctrl+o to go to the previous location.

Zoom & fit

Zoom in/out with = and -. Reset with 0. Fit modes are separate commands (fit width/height/window) so you control exactly what happens. 

[ui.zoom]
level = 1.0
factor = 1.25

[ui.layout]
initial_fit = "width"

Search

Press / to search the document. Jump through hits using n and Shift+N.

Search hits on scrollbar

If enabled, dodo draws markers on the scrollbar for search hits so you can see hit distribution at a glance. 

[ui.scrollbars]
search_hits = true
Highlighting search index
dodo can draw the “current hit” differently (color is configurable). This helps when there are lots of matches.

Links

Link hints

Press f to show link hints and jump without touching the mouse. Copy a hinted link using Shift+F. 

[keybindings]
link_hint_visit = "f"
link_hint_copy = "Shift+F"

[ui.link_hints]
size = 0.25

URL detection

If a PDF contains plain URL text that isn’t a real PDF link object, dodo can still detect it and make it clickable. 

[ui.links]
detect_urls = true
url_regex = "(https?://|www\\.)[^\\s<>()\\\"']+"
URL regex can be dangerous
If you make the regex too greedy, you’ll create trash links everywhere. Keep it conservative.

Annotations

Highlights

In highlight mode, you mark text and it remains searchable (useful for revisiting notes).

Rectangles & popups

Rectangle annotations and popups are supported. Popups are the closest thing to “sticky notes”.

Undo/redo
Annotation actions are undoable. The undo history size is configurable: 
[behavior]
undo_limit = 25

SyncTeX

If you read LaTeX PDFs, SyncTeX lets you jump between the PDF and the source. dodo launches your editor using a configurable command: 

[behavior]
synctex_editor_command = "zeditor %f:+%l"
Format
%f is the source file and %l is the line number.

Command palette

Press Ctrl+Shift+P to open the command palette. It’s the fastest way to discover commands if you don’t remember the binding. 

[ui.command_palette]
show_shortcuts = false
height = 400
width = 600

Tip: If you want it to act like “help”, enable shortcuts so the palette becomes a built-in cheat sheet.

LLM

If dodo is compiled with LLM support, an LLM panel can be shown and configured. If not compiled, this section does nothing. 

[llm]
provider = "ollama"
model = "llama3.2:3b"
max_tokens = 512

[ui.llm_widget]
visible = true
panel_width = 400
Reality check
LLM support is optional. Don’t depend on it for core reading workflow.

Tips

  • Enable search_hits if you read long papers. It’s worth it.
  • Bind the few commands you actually use. Don’t memorize a giant keymap.
  • If you hate the UI, you can disable most of it (menubar, panel, tabs).
  • Keep your config in git. It’s small and it matters.
