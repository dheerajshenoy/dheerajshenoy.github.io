Installation
MuPDF is pinned

dodo downloads and builds MuPDF 1.27.0 automatically. If a newer MuPDF breaks the build, edit MUPDF_VERSION inside install.sh and pin a known working version.

Installer options 
$ ./install.sh --help
  • --prefix <path> install prefix (default: /usr/local)
  • --skip-mupdf-build skip building MuPDF (only if MuPDF is already available under the prefix)
  • --debug / --release — set CMake build type
  • --with-llm-support — enable LLM support at configure time
  • --cmake-arg / --cmake-args — pass extra CMake flags (useful for weird setups)
